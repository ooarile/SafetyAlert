세이프티 알람 수신 앱 — 설치 안내
====================================

이 폴더의 파일을 알람을 받을 PC에 복사해 설치합니다.
인터넷 연결은 필요하지 않습니다. .NET 등 별도 설치도 필요 없습니다.


1. 준비
-------
알람 서버 담당자에게 다음 세 가지를 받으십시오.

  - 알람 서버 주소   예) 192.168.0.10:8080
  - 구독 계정        기본값 safety-viewer
  - 계정 비밀번호

서버 설치 시 화면에 출력되며, 서버의 /opt/safety/.env 에도 남아 있습니다.


2. 설치
-------
(1) 이 폴더를 알람 수신 PC로 복사합니다.

(2) PowerShell 을 "관리자 권한으로 실행" 한 뒤, 이 폴더로 이동해 실행합니다.

      cd <이 폴더 경로>
      powershell -ExecutionPolicy Bypass -File .\설치.ps1

    설치 스크립트 없이 수동으로 하려면 SafetyAlarm.exe 와 settings.json 을
    C:\Program Files\SafetyAlarm\ 에 복사하고, Win+R 로 shell:startup 을 연 뒤
    exe 바로가기를 만들면 됩니다.

(3) 설정 파일을 수정합니다.

      C:\Program Files\SafetyAlarm\settings.json

      "Server"   : 알람 서버 주소 (포트까지, http:// 는 빼도 됩니다)
      "Password" : 구독 계정 비밀번호

    Topic 과 User 는 서버 담당자가 다르게 알려준 경우에만 바꾸십시오.

(4) 실행합니다. PC를 재시작해도 자동으로 실행됩니다.

      Start-Process 'C:\Program Files\SafetyAlarm\SafetyAlarm.exe'


3. 정상 동작 확인
-----------------
작업 표시줄 오른쪽 아래 트레이 아이콘(노란 경고 표시)에 마우스를 올립니다.

  "세이프티 알람 — 연결됨"        정상입니다.
  "세이프티 알람 — 연결 끊김"     아래 4번을 보십시오.

트레이 아이콘 우클릭 → "연결 상태" 로 현재 설정을 확인할 수 있습니다.
"테스트 알림" 을 누르면 알림이 화면에 뜨는지 확인할 수 있습니다.


4. 연결이 안 될 때
------------------
앱이 원인을 판정해 알림으로 알려줍니다. 알림을 놓쳤다면 아래 파일을 보십시오.

  C:\Program Files\SafetyAlarm\safety-alarm.log

  "설정이 필요합니다"          settings.json 을 수정하지 않았습니다.
  "연결할 수 없습니다"         서버 주소 오타, 서버 미기동, 방화벽 차단.
                               서버 담당자에게 8080 포트 허용을 확인하십시오.
  "인증 실패"                  비밀번호 또는 토픽 권한 문제입니다.
  "토픽을 찾을 수 없습니다"    Topic 값이 서버와 다릅니다.
  "실시간 연결에 실패"         중간 장비가 WebSocket 을 막고 있습니다.


5. 참고
-------
- 이 프로그램이 실행 중일 때만 알람을 받습니다. 종료하지 마십시오.
- 화면이 꺼져 있어도 받습니다. PC 전원이 켜져 있어야 합니다.
- 코드 서명이 없어 실행 시 SmartScreen 경고가 뜰 수 있습니다.
  "추가 정보" → "실행" 을 누르거나, 사내 보안 정책에 예외 등록을 요청하십시오.
- 제거하려면 트레이에서 종료 후 C:\Program Files\SafetyAlarm 폴더와
  시작 프로그램 바로가기(shell:startup 안의 SafetyAlarm)를 삭제하면 됩니다.
